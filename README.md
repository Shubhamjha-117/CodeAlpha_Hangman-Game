# 🎮 Hangman Game using Python

A simple, console-based Hangman game developed using Python. The player has to guess a randomly selected hidden word one letter at a time before running out of attempts.

## 📌 Project Overview

Hangman is a word-guessing game where the computer selects a word from a predefined list of five words. The player must guess the word by entering individual letters.

The player gets a maximum of **6 incorrect guesses** to identify the complete word.

## ✨ Features

- Random word selection using Python's `random` module.
- Five predefined words.
- Letter-by-letter guessing.
- Displays correctly guessed letters.
- Tracks incorrect guesses.
- Maximum of 6 incorrect attempts.
- Displays win or lose messages.

## 🛠️ Technologies Used

- Python 3
- `random` module
- Conditional statements
- Loops
- Strings and lists

## 🎯 How to Play

1. Run the program.
2. The computer selects a random word.
3. Enter one letter at a time.
4. Correct guesses reveal the matching letters.
5. Incorrect guesses reduce your remaining attempts.
6. Guess the complete word before reaching 6 incorrect attempts to win!
